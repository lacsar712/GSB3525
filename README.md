# 居家养老服务系统 (Elderly Care System)

基于 Spring Boot + Vue3 的全栈工程，专为实现老年人居家养老服务设计的系统。支持角色：老人/子女、护理员、机构管理员、平台管理员，全站已中文化并完全容器化适配。

## 🛠 技术栈
- Frontend: Vue 3 + Vite + Element Plus + TailwindCSS
- Backend: Spring Boot 3 + MyBatis-Plus + JWT
- Database: MySQL 8.0

## 🚀 启动指南 (How to Run)
1. 确保 Docker 和 Docker Desktop 已启动。
2. 在根目录执行：
   ```bash
   docker compose up --build -d
   ```
3. 等待容器启动完成，可能需要 1-3 分钟（依赖于网络，后端使用了阿里云 Maven 源以加速构建，前端使用了 npm 淘宝镜像源）。

## 👥 角色权限矩阵 (Role Matrix)

| 角色 | 登录入口 | 主要功能 |
| :--- | :--- | :--- |
| **老人/子女** | `/web` | 下单预约、上传健康指标、报名活动、积分换购、匿名树洞、阅读科普 |
| **护理员** | `/app` | 移动端接单、现场签到、服务前后双测、查看个人评分与结算 |
| **机构管理员** | `/org` | 维护养老服务类型、工单派发调优、财务对账与结算 |
| **平台管理员** | `/platform` | 机构准入审核、投诉仲裁、全数据大屏监控、审计日志、系统配置 |

## ✅ 核心功能验证 (Verification)
1. **老人发单与健康档案**：使用 `senior1` 登录 `/web`，在【预约下单】里找一个服务并提交；在【健康数据】里上传一次血压记录。
2. **机构审核与派单**：使用 `org1` 登录 `/org`，在【派单大厅】中可以看到刚才老人刚下的订单，点击“派单”分配给张阿姨。
3. **护理员接单与评价**：使用 `carer1` 登录 `/app`，进入工作台可以查看到刚才派来的新订单。点击【开始服务】到【完结并评价】，拍照上传结单照片。
4. **积分与社交互动**：回到 `/web` (作为 `senior1`)，进入【积分商城】将护理员刚刚完单积攒的积分兑换一件商品；在【树洞】发布一条匿名情感动态并查看评论。
